# Car Rental System
## Description
An offline desktop application built with C# WinForms and SQLite for managing car rental operations.

- Windows Forms (WinForms)
- SQLite

## Features
- Secure login with BCrypt password hashing
- Customer management (CRUD)
- Car inventory management (CRUD)
- Automatic rental bill calculation
- Offline operation - no internet required
